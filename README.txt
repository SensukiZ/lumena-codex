# Lumena Codex Website

This folder is a ready-to-upload static website.

## Files
- `index.html` — the complete Lumen Codex
- `robots.txt` — allows search engines to crawl the page

## GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` and `robots.txt` to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will provide the public website URL.

## Important
The Codex currently uses the existing HTTPS assets hosted by `lumena.gg` for artwork/type icons, and it also loads Google Fonts. Those resources therefore need an internet connection.

The existing Codex interactions and data are kept in the HTML rather than being replaced with a new implementation.
